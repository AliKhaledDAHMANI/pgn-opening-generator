Worth looking at specifically:

- **`two-knights-trap.pgn`** - the trap sits in a sideline: 4.Ng5 baits 4...Nxe4,
  and 5.Bxf7+ is the engine-verified punishment (154 cp swing). The bait itself is
  a sound book move, which is what separates a trap from a gift.
- **`italian-rare-3d5.pgn`** - starts from a position outside the ECO book
  (3...d5), so the engine carries the whole line while the request's "aggressive"
  style still shapes the choices.
- **`white-repertoire-1e4.pgn`** - one consistent White line with a branch for
  each notable Black reply. The pinned reply (1...e5) gets no branch, because the
  caller asked about that move specifically.
- **`engine-mode-objective.pgn`** - `--mode engine` ignores theory preference and
  plays Stockfish's top move at every ply.

Regenerate any of them by running the command from the repository root. Output is
deterministic, so the same command on the same machine and engine build
reproduces the file byte for byte. A different Stockfish version will produce
different (equally valid) lines.
